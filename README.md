# 印刷拼版预检与打样轮次审批平台

面向印刷生产团队的拼版工作台，支持页面尺寸与印刷规格、Canvas 版位编辑、出血/安全区/折手/页码检查、打样反馈、版本并排对比、审批锁定和可恢复导出任务。

## 技术栈

Vue 3 + PrimeVue + Pinia + Vue Router + TanStack Query + Axios + Canvas + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62050`。

## 核心工作流

- 导入页面尺寸、出血、安全区、折手和装订方向，在 Canvas 中拖拽版位。
- 自动检查页面缺失、出血不足、页序冲突、版位重叠和装订错误。
- 每轮打样记录样张照片、色差反馈、修正说明和负责人决定。
- 版本并排对比、审批锁定，并恢复中断的导出任务。

## 版本锁定 / 失效联动 / 断点续传

三者通过「锁定快照」绑定为同一条事实链，保证交付包一定对应审批过的那一版：

1. **锁定即留快照**：审批锁定时生成版本号（`V-0001`…），快照冻结当时的全部版位与「通过」的打样结论（含指纹）。
2. **改动即失效**：锁定后版位一改动，或已通过的打样被退回，该版本的快照立即失效；所有绑定该版本的导出任务（排队、生成中、中断）**立即变为「已失效」并回到待生成语义**，已产出的成品与分片保留但只作历史查看，不再可交付。需修订后重新锁定出新版本再生成。
3. **按锁定快照续传**：导出按 2 页/分片执行；续传必须携带版本号与快照指纹，服务端比对任务内嵌快照，不一致返回 `VERSION_CHANGED`，**新分片不会写进旧任务**。失败后从第一个未完成（失败）分片重试，已完成分片按哈希复用。
4. **单标签接管**：每个任务只有一个续传租约（4 秒心跳）。两个标签页同时续传时只有一个接管，另一个收到「版本已变化 / 任务已被接管」提示并停止写入；租约过期后可强制接管，原持有方下一次心跳收到 `TAKEN_OVER`。跨标签页状态通过 `localStorage` + `BroadcastChannel` 同步。
5. **旧稿迁移**：升级前没有版本号的数据（v1）迁移后归入「未锁定历史」，可查看但不可续传、不可作为交付依据；其旧导出任务同样标记为 legacy。

导出页提供「模拟当前分片失败」「强制接管」等入口，便于演示断点恢复与双标签冲突；历史结果对话框展示任务绑定版本、快照指纹、分片状态与成品哈希，并明确标注「不能作为交付依据」。
